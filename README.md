Overview/Exposé-like task viewer tested on labwc 0.91+ to display the current tasks and make them active/focused. Other wlroots compositors may work, as well. It aims to be a Wayland replacement for skippy-xd.

Version 0.5 adds proper icons for each task and a few css styles to match your preferences.

- make sure to install: wlrctl
- make sure to install the required python dependencies
- chmod +x tasklist-overview.py
- bind it to a convenient key combo / mouse button (rc.xml on labwc)
- enjoy!
